# Mis Motoras Favoritas

Este proyecto fue creado como parte de una asignación de desarrollo web.

La página utiliza HTML, CSS y Bootstrap para crear una interfaz responsiva y funcional.

## Tecnologías utilizadas

- HTML5
- CSS3
- Bootstrap 5
- GitHub
- GitHub Pages

## Contenido del proyecto

La página incluye:

- Barra de navegación
- Tarjetas de motocicletas
- Imágenes
- Botones
- Diseño responsivo
- Formulario de contacto
- Footer

## Motocicletas incluidas

- Kawasaki Z900
- Yamaha MT-09
- Yamaha R1

## Página publicada

El proyecto está disponible mediante GitHub Pages.
